# 临湖 · Ante Lacus

antelacus.com 的美学。本文是规则，不是描述：每一个视觉与交互决定都应能在这里找到依据；找不到依据的元素，先回到「一、立场」判断它该不该存在。数值（色值、字号、间距）住在 `src/app/globals.css` 的变量里，这里只写它们的角色与界线。无障碍的底线是 WCAG 2.2 AA，美学只在它之内做选择。

## 一、立场

**古典中国的内核，现代的形式。** 访客首先感到的是好用、精美，然后才隐约感到它的根。中国内核放在结构里——留白、节奏、段落、分寸——不放在表面的纹样与道具上。一切元素都只是载体。

**临而不摹。** 书法学古帖有两法：摹，蒙纸描形，形状不差而笔意尽失；临，置帖于旁，看而自书，形不必全似而得其笔意。姜夔《续书谱》：「临书易失古人位置，而多得古人笔意；摹书易得古人位置，而多失古人笔意。」本站只临不摹：先问一件古典事物为人做了什么，再用屏幕本来就有的东西——光、字、空白、时间、链接——做到同一件事；不让屏幕假扮成纸、石或墨。齐白石所谓「妙在似与不似之间，太似为媚俗，不似为欺世」，是同一把尺。

**指认测试。** 如果访客能指着某一个元素说「这就是中国的部分」，这个元素就失败了。中国感只应从整体里生出，指不出来源——如苏州博物馆：没有一根雕梁，走一圈谁都知道是苏州。

**一个环境，而非主题。** 只有一种纸，没有暗色模式。

## 二、结构

这是内核所在。

- **计白当黑。** 空白与笔画同等重要。每一块留白都是被经营的构图，不是间距参数的余数；拿不准时，多留白，少放东西。
- **手卷。** 文章页分三段：**引首**（日期、标题、导语，有封面则在此）、**画心**（正文，不受任何干扰）、**尾纸**（题跋；末行是「回到顶部」——有目录时另有「目录」——终止符落在这一行的末尾）。内容始终静止、一次全部在场；展开靠读者的滚动，页面不表演展开。
- **题跋。** 元数据不散落在正文四周，集中写在尾纸：写于何时、标签、语言。开头只留日期——读者要靠它判断内容是否过时。
- **印。** 作者的签名抽象为一枚**终止符**：朱砂色的小方块，摆正、静止。它在首页格言之后、在文末，都表示「写完了」；西方读者读作杂志的终止符，中国读者隐约感到落印。全站只有这一种形态，每页至多一处。
- **框景，欲扬先抑。** 首页先收：门上只有名字、格言与终止符；再放：透过几扇窗瞥见园中，而不陈列全园。景越少，每一处越重。
- **中文排版。** 中文正文按书籍排印的习惯：行距宽于西文（约 1.9）、两端对齐、一行约三十六字、标点与中西文间距规整。这是指认不出、只让人觉得「读着舒服」的中国内核。
- **三种页面，三种形态。** 首页是门与窗，列表页是目录，文章页是手卷。形态跟着任务走，不以一种卡片套全站。

## 三、材料

**材料极少。** 颜色少、字体少、效果少；每加一样，先问它是临还是摹。

**色。** 五色，各司其职：

| 色 | 角色 |
|---|---|
| 纸 | 唯一的底 |
| 墨 | 文字，以及读者一切交互的形态：键盘焦点环、选中态（墨底纸字的反白） |
| 朱砂 | **只属于作者**：全站红色只有终止符。链接、悬停、焦点、选中、当前页一律不用 |
| 苔 | 回应：悬停与按下时纸色转为苔色 |
| 石 | 结构：代码块、引用块、区块底色 |

次要文字用墨的浅档，但对比度不低于 AA（正文 4.5:1）。颜色从不独自承载意义，选中与当前总有形态上的区别。

**字。**

| 角色 | 字体 | 用在 |
|---|---|---|
| 门 | Cormorant Garamond | 只用于首页的名字与格言——全站唯一有表情的声音，限定在一处才珍贵 |
| 标题、正文 | Source Serif 4 + 思源宋体 | 其余一切文字。二者按一家设计，中英混排的标题气质一致 |
| 代码 | JetBrains Mono | 代码、命令、路径 |

**光与深度。** 纯平。纸不会浮起：没有投影、没有上浮、没有文字阴影。深度只由苔、石两种晕染色的叠加表达。

**图像。** 只有作者的照片是图像的主角。照片外框一道细墨线。文章与项目的封面属于内容、不受本文约束，因此只在文章页引首出现，不上首页与列表页。

## 四、动

**页面自己从不动。** 一切动效只回应读者的动作；没有入场动画、没有无限循环、没有回弹、没有随滚动显现、没有随机。

被允许的只有三种：

- **悬停与按下**：纸转苔、标题墨色加深，一步完成，约 0.25 秒。它只确认「你正指着这里」，从不揭示新信息。
- **页面切换**：约 0.15 秒的淡入淡出，浏览器不支持则直接切换。
- **展开与收起**：菜单、对话框、目录，在读者点击后出现或消失。

**悬停不藏信息。** 读者决定「要不要读」所需的一切——标题、日期、语言、类型、标签——常驻可见；触屏没有悬停，键盘不产生悬停。「静默」是语气（轻、淡、少），不是隐藏。

## 五、页面

- **首页**：门（名字，与以终止符收束的拉丁文格言，完全静止）＋ 框景「一窗主景」：最新一组视觉作品的封面为大窗，专栏、闪念、实验室各以最新一篇为文字窗。相册封面因此也是首页的门面。
- **列表页**：目录——每篇一行：标题、摘要、日期、标签。视觉的列表例外，为照片网格。
- **文章页**：手卷三段。小标题足够多的长文，在引首之后放一行折叠的目录，读者点开才展开。
- **导航**：静止在页首，随页面滚走；不固定、不自动隐藏。读到一半要回去，靠尾纸末行的「回到顶部 · 目录」、⌘K / Ctrl+K 搜索与系统自带的回到顶部（iOS 轻点状态栏），不靠一条跟随读者的导航。

## 六、拒绝清单

以下一律不用，出现即回炉：

- 摹形的道具：纸张纹理、石刻阴影、笔墨晕开动画、印章的篆字或印泥质感
- 符号拼贴：回纹、祥云、灯笼、毛笔字标题、任何可被指认的「中国元素」
- 投影、上浮、玻璃、渐变、光晕
- 入场动画、错落淡入、循环动画、回弹缓动、逐字动画、随机倾斜与随机色差
- 只在悬停时出现的信息
- 朱砂用于任何读者交互
- 固定或自动隐藏的导航
- 首页与列表页上的文章封面；「精选」「热门」之类的标注
- 卡片套卡片；为每个区块都画框
- 巨幅首屏大图

## 七、审查顺序

一处设计完成后，依次过：

1. **指认**：能否指着某处说「这是中国元素」？能，则失败。
2. **临摹**：这一处是在转译一种感受，还是在模仿一种材料的外观？
3. **朱砂**：页面上的红色是否只有终止符？
4. **静止**：不碰任何东西时，页面上有没有东西在动？
5. **可达**：只用键盘、只用触屏，能否看到并用到一切？
6. **对比**：文字 4.5:1，控件边界与焦点 3:1。
7. **留白**：还能拿掉什么？

## 八、格言

**Ante Lacus, Pax Mentis** —— 临湖之前，心境平和。

拉丁文的材料，中国的骨架：二二相对如对句，不用动词，只并置一景一心，如「枯藤老树昏鸦」。湖与心安是东西方共有的意象（心如止水；叶芝 *I shall have some peace there*）。*lacus* 在此为复数宾格，严格读作「诸湖之前」。首页只放拉丁文、标 `lang="la"`；释义放在关于页。
