# GLOSSARY

跨版本、跨 feature 都会用到的词。只在一个 feature 里用的词留在该 feature 的 REQ §1.4；美学词汇（纸、墨、朱砂、引首、尾纸、终止符、框景……）的归宿是 `docs/aesthetic-thesis.md`。

## 无障碍

- **WCAG**（Web Content Accessibility Guidelines）：W3C 的网页无障碍标准，本项目用 2.2 版。各国法规（欧盟 EAA、美国 ADA）多以它的 AA 级为基准。原文：https://www.w3.org/TR/WCAG22/
- **成功准则**（Success Criterion，SC）：WCAG 里一条可判定的要求，编号「原则.指南.准则」，如 1.4.3。文档与测试里以编号引用。
- **一致性等级 A / AA / AAA**：每条成功准则属于一个等级。A 是最低门槛；AA 是业界与法规通行的「达标」线，包含 A；AAA 是加分项，不要求全部满足。「达到 AA」= 所有 A 与 AA 的准则都满足。
- **对比度**：文字色与背景色的亮度比，1:1（相同）到 21:1（黑白）。AA 要求正文 ≥ 4.5:1、大字（≥ 24px，或 ≥ 18.7px 粗体）≥ 3:1（1.4.3）；控件边界与焦点指示 ≥ 3:1（1.4.11）。
- **屏幕阅读器**（读屏）：把页面读出来的软件，视障用户靠它和键盘或手势操作。主流：VoiceOver（Apple）、TalkBack（Android）、NVDA（Windows）。
- **无障碍树**：浏览器从页面生成、交给屏幕阅读器的结构——每个元素的角色（按钮、链接、标题）、可访问名称与状态。屏幕阅读器「看到」的是它，不是画面。
- **可访问名称**：屏幕阅读器念出的元素名字，来自可见文字、`alt`、`aria-label` 等。图标按钮没有它，读屏只会念「按钮」。
- **焦点 / 焦点指示**：键盘用户当前所在的元素，按 Tab 移动；焦点指示是画出它在哪的那圈线。AA 要求焦点可见（2.4.7）、不被固定头部等遮住（2.4.11）、顺序合理（2.4.3）。
- **仅悬停内容**：只在鼠标悬停时出现的信息或控件。触屏没有悬停、键盘不产生悬停，这些用户就看不到它（1.4.13、2.1.1）。
- **重排**（reflow）：页面在 320px 宽（相当于桌面放大到 400%）下不出现横向滚动、内容不丢失（1.4.10）。
- **目标尺寸**：可点目标至少 24×24 CSS 像素，或周围留足间距（2.5.8，2.2 版新增）。
- **减少动画**：系统设置里的「减弱动态效果」，页面经 `prefers-reduced-motion` 读到它。对应的准则 2.3.3 属于 AAA。
- **axe**：Deque 出的自动无障碍检查引擎，读页面结构与样式判定一部分成功准则；焦点顺序是否合理、读屏念出来是否听得懂等，它判定不了，要人工。

## 测试

- **等价类**：行为相同的一组输入，每类测一个代表即可。设备覆盖按等价类做——渲染引擎、视口宽度、输入方式（能否悬停、指针粗细）、用户设置、辅助技术——而不是按设备型号。
- **能力查询**：CSS 按设备能力而非型号分支，如 `@media (hover: hover)`、`@media (pointer: coarse)`。
